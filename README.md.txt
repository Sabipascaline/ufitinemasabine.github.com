# Project Title

# My Personal Portfolio

A comprehensive personal portfolio showcasing my skills, projects, education, 
and professional experience. This portfolio demonstrates my journey as a Technical Support Engineer
and serves as a complete overview of my academic and professional achievements.

## Features

- "About Me Section": Credentials, professional summary, location, picture, and personal details
- "Projects Section": Complete project details including descriptions, deliverables, duration, and status
- "Education Section": Institutions attended, qualifications, major courses, and awards
- "Awards & Recognition": Notable achievements and certifications
- "Contact Information": Email, phone, and social media links
- "References Section": Professional references with contact details

## How to run this project

This project is a personal portfolio website hosted on GitHub Pages.

"Access the live portfolio here:" https://github.com/Sabipascaline/ufitinemasabine.github.com.git

Or clone and view locally on your computer.

### Prerequisites
Packages or software users need to install first to access this project
 1. Git bash
 2. Visual Studio Code
 3. Any browser 

### Installation

1.Create a GitHub account if you don't have one.
2.Install 'Git Bash' and 'Visual Studio Code'.
3.Clone the repository: https://github.com/Sabipascaline/ufitinemasabine.github.com.git
4.Navigate to the project folder.
5.Open with your browser to view the portfolio.
